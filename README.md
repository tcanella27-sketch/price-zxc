## Запуск

1. Установите Node.js 18 или новее.
2. Откройте папку `local_schedule_background_site` в терминале.
''' bash 
cd C:/путь к папке local_schedule_background_site
'''

3. Выполните:

npm install
npm start

4. Откройте:
http://localhost:3000


## Расписание

- Будни, утро: с 08:00 до 13:00
- Будни, вечер: с 13:00 до 08:00 следующего дня
- Выходные, утро: с 08:00 до 13:00
- Выходные, вечер: с 13:00 до 08:00 следующего дня

Суббота и воскресенье автоматически считаются выходными.
Даты из списка исключений тоже считаются выходными.

## Список праздничных и других выходных дат

Откройте файл:

public/config.js

В массиве `WEEKEND_EXCEPTIONS` уже добавлены даты с 1 по 9 января:

```js
const WEEKEND_EXCEPTIONS = [
  '01-01',
  '01-02',
  '01-03',
  '01-04',
  '01-05',
  '01-06',
  '01-07',
  '01-08',
  '01-09'
];
```

Можно добавлять даты в двух форматах:

MM-DD       — выходной каждый год, например 05-09
YYYY-MM-DD  — выходной только в конкретном году, например 2026-12-31
