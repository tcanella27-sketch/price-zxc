# PRICE RR — локальный прайс по расписанию

Локальный сайт автоматически показывает нужный набор изображений в зависимости от дня недели и времени суток.

В каждом режиме используется по 3 изображения. Они автоматически переключаются каждые 30 секунд.

---

## Запуск проекта

### 1. Скачайте проект с GitHub

На странице репозитория нажмите:

**Code → Download ZIP**

Сохраните ZIP-архив на диск `C:`.

Рекомендуемый путь:

```text
C:\PRICE_RR.zip
```

Распакуйте архив в отдельную папку на диске `C:`.

После распаковки путь к проекту должен выглядеть примерно так:

```text
C:\PRICE_RR\local_schedule_background_site
```

> Не запускайте проект непосредственно из ZIP-архива. Архив обязательно нужно сначала распаковать.

### 2. Установите Node.js

Установите **Node.js версии 18 или новее**.

После установки откройте PowerShell и проверьте версию:

```powershell
node --version
```

Также проверьте наличие `npm`:

```powershell
npm --version
```

### 3. Откройте папку проекта в терминале

Перейдите в папку проекта:

```powershell
cd "C:\PRICE_RR\local_schedule_background_site"
```

Путь может отличаться в зависимости от названия распакованной папки.

### 4. Установите зависимости

Команда выполняется только при первом запуске или после обновления зависимостей:

```powershell
npm install
```

### 5. Запустите сайт

```powershell
npm start
```

После успешного запуска в терминале появится сообщение о работающем сервере.

### 6. Откройте сайт

Откройте браузер и перейдите по адресу:

```text
http://localhost:3000
```

Не закрывайте окно терминала, пока сайт используется. При закрытии терминала локальный сервер остановится.

## Расписание

Сайт автоматически выбирает один из четырёх режимов:

| День | Период | Время |
|---|---|---|
| Будни | Утро | 08:00–13:00 |
| Будни | Вечер | 13:00–08:00 следующего дня |
| Выходные | Утро | 08:00–13:00 |
| Выходные | Вечер | 13:00–08:00 следующего дня |

Суббота и воскресенье автоматически считаются выходными днями.

Даты, добавленные в список исключений, также работают по расписанию выходного дня.

---

## Изображения

Для работы сайта используются 12 изображений:

- 3 изображения — будни, утро;
- 3 изображения — будни, вечер;
- 3 изображения — выходные, утро;
- 3 изображения — выходные, вечер.

Внутри каждого режима изображения переключаются автоматически каждые 30 секунд.

При замене изображений необходимо сохранить исходные названия файлов.

## Праздничные и дополнительные выходные дни

Откройте файл:

```text
public/config.js
```

В массиве `WEEKEND_EXCEPTIONS` уже добавлены даты с 1 по 9 января:

```js
const WEEKEND_EXCEPTIONS = [
  '01-01',
  '01-02',
  '01-03',
  '01-04',
  '01-05',
  '01-06',
  '01-07',
  '01-08',
  '01-09'
];
```

### Поддерживаемые форматы дат

#### Ежегодный выходной

Формат:

```text
MM-DD
```

Пример:

```js
'05-09'
```

Такая дата будет считаться выходным днём каждый год.

#### Выходной только в конкретном году

Формат:

```text
YYYY-MM-DD
```

Пример:

```js
'2026-12-31'
```

Такая дата будет считаться выходным только в указанном году.

### Пример добавления новых дат

```js
const WEEKEND_EXCEPTIONS = [
  '01-01',
  '01-02',
  '01-03',
  '01-04',
  '01-05',
  '01-06',
  '01-07',
  '01-08',
  '01-09',
  '05-09',
  '2026-12-31'
];
```

После изменения файла сохраните его и перезапустите сайт:

```powershell
npm start
```

Для остановки работающего сервера нажмите в терминале:

```text
Ctrl + C
```

## Обновление проекта с GitHub

После загрузки новой версии скачайте свежий ZIP-архив через:

**Code → Download ZIP**

Затем:

1. Остановите сайт сочетанием `Ctrl + C`.
2. Распакуйте новую версию проекта.
3. Замените старую папку проекта новой.
4. Откройте новую папку в терминале.
5. Выполните:

```powershell
npm install
npm start
```

## Возможные проблемы

### Команда `node` не найдена

Установите Node.js, затем полностью закройте и заново откройте PowerShell.

### Страница не открывается

Убедитесь, что в терминале выполнена команда:

```powershell
npm start
```

Проверьте адрес:

```text
http://localhost:3000
```

### Изображения не обновились

Проверьте, что:

- изображения находятся в правильной папке;
- названия файлов не изменены;
- расширения файлов совпадают с указанными в настройках;
- браузер был обновлён сочетанием `Ctrl + F5`.
